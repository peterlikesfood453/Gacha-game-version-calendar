How to get it on your phone

  1. iPhone: open this page in Safari and tap the black button. With one game selected it opens straight in Calendar - tap Add All. With several, it downloads a file: open it from the Files app.
  2. Android / Huawei / Xiaomi: the button downloads a .ics file - import it with your calendar app.
  3. To follow updates long-term, skip importing and use Subscribe below - your phone syncs automatically when the data changes.
  4. Reminders are already set: 30 min before a stream, 2 h and 30 min before codes expire, 1 day and 2 h before a version update.

The "codes expire" entry is the official cut-off time exactly. The rule differs per game: Genshin noon on day 3 after the stream, Star Rail 23:59 the next day, ZZZ and WuWa 23:59 on day 2, NTE 23:59 on day 4. Endfield, Where Winds Meet and HoK: World do not hand out preview codes, so they have no such entry.

Subscribe & remove

One game, one calendar. If you quit a game, turn off or delete just that calendar and its reminders go away while the rest keep working. iPhone can delete directly; on Android read the red box below first.

  1. Open your calendar app: Settings → Calendar accounts (names vary by vendor)

  3. Switch "show" off - do not tap Delete

Not worth the hassle: use a different calendar app

Install ICSx⁵ (open source, free, on every app store). Each subscription becomes an independent calendar there, so deleting one never touches the others. Just paste the subscribe URL - the Subscribe button copies it for you.

Only want some quiet? You do not have to delete anything: switch that calendar's visibility off and reminders stop too, or hit "remove alerts" in the subscription settings and keep the events.
How to subscribe on Android (when the button says "copied")

Android calendar apps do not accept webcal:// links, so the button copies an https:// URL instead.

Recommended: install ICSx⁵ (open source, free). Open it → + (top right) → paste the URL → save. Every game becomes its own calendar, deleting one never affects the others, and you dodge the vendor account behaviour entirely.

The built-in calendar app works too, with a catch:

  1. Open the calendar app and find Add calendar from URL / Subscribe by URL in settings
  2. Paste the URL, name it whatever you like, confirm
  3. It re-fetches the URL periodically. Note that subscriptions added this way all land in one account, so deleting one deletes all - turn off "show" instead when you stop playing a game
I imported the file once - how do I undo it?

Imported events live on your phone, so nothing on my side can reach them. Delete them in the calendar app:

  1. Open your calendar app and search for the game name
  2. Each result can be deleted on its own (iPhone: tap in → Delete Event; Android: long-press → Delete)
  3. Or switch to subscribing instead - then removing a game means deleting one calendar

Why can't this page just delete it remotely? Calendar subscriptions are read-only - only your own phone knows what you subscribed to. So removal has to happen on your device. I kept it to three taps.

This is the static build - how is it different?

Everything on this page is computed in your browser, with no server involved, so it can live on GitHub Pages for free and anyone can host a copy.

  1. What works: tick any set of games and download one merged .ics file for your phone; subscribe per game to a pre-built file.
  2. What does not: a subscribable URL for an arbitrary mix like "Genshin + WuWa". A subscription URL has to point at a file made in advance, so you get one per game plus one for everything.
  3. How data updates: the maintainer edits events.py and rebuilds - page and subscriptions change together. Subscribers sync automatically; people who imported need to import again.

Need a subscribe link for a custom mix? Use the full version in the repo (a small Python server) - there the URL is generated from whatever you pick.

Confirmed comes from official announcements, Estimated is projected from the version cycle, TBC means no date announced yet.
Computed is the code expiry time: not announced officially, but derived from each game's past record to the minute - usually within an hour.
Expired codes are never reissued, so do not treat that entry as a price reference.
