怎么加到自己手机上

  1. iPhone：用 Safari 打开本页 → 点底部黑按钮。只选了一款会直接跳进日历，弹窗点 「全部添加」；选了好几款会下载一个文件，到「文件」App 里点开它即可。
  2. 安卓 / 华为 / 小米：点黑按钮会下载 .ics 文件，再用系统日历的「导入」选中它。
  3. 想长期跟着更新，别用导入，用下面的订阅：以后数据更新了，手机上自动同步。
  4. 提醒都设好了：前瞻提前 30 分钟；兑换码失效提前 2 小时和 30 分钟；版本更新提前 1 天和 2 小时。

日程里那条「兑换码失效」，时间就是官方的截止时刻。各游戏口径不同：原神是直播后第 3 天中午 12:00，星铁是次日 23:59，绝区零和鸣潮是第 2 天 23:59，异环是第 4 天 23:59。终末地、燕云十六声、王者荣耀世界不发前瞻兑换码，所以没有这一条。

订阅与取消

一个游戏一个日历。退坑了，关掉或删掉对应那一个日历，那个游戏的前瞻和更新提醒就一起没了，其他游戏照常。iPhone 可以直接删；安卓要看清下面那条红字。

按游戏订阅
取消「」的提醒
安卓先看这条，别直接点删除。很多国产日历（vivo / OPPO / 小米 / 华为）用「导入账号 · 从网址订阅」加进去的多个日历，会全部塞在同一个叫 Subscription Calendar 的账号下面。你在账号管理里删掉其中一个，会把所有同类订阅一起删掉，原神和星铁同时消失就是这么来的。这不是本站的问题，是厂商日历 App 的实现方式。安卓请按下面第 2 条做。
iPhone / iPad
  1. 打开日历 App，点屏幕最下方的「日历」按钮
  2. 原神 · 版本日历，点它右边的 ⓘ
  3. 往下滑，点删除日历并确认。iOS 每个订阅是独立的，只删这一个
安卓（想单独关掉某一款）
  1. 进日历 App 的设置 → 日程账号管理（各家叫法略有不同）
  2. 点 原神 · 版本日历 那一行（这几行的标题都写「Subscription Calendar」，认下面那行小字）
  3. 用里面「显示」开关关掉，不要点「删除」
  4. 关掉后这个游戏的提醒立刻停，其他游戏不受影响。想真正逐个删干净，用下面说的 ICSx⁵
不想折腾：换一个日历 App

装 ICSx⁵（开源免费，应用商店搜得到），每条订阅在它里面是独立日历，删哪条就删哪条，不会连带。把订阅地址粘进去即可，本站的「订阅」按钮复制出来的就是地址。

只是暂时不想被打扰，不用删：把那个日历的「显示」关掉（隐藏），提醒也会停；或者进订阅设置点「移除提醒」，日程留着。
安卓怎么订阅（按钮提示"已复制"时看这里）

安卓的日历 App 不吃 webcal:// 开头的地址，所以按钮会改成复制 https:// 开头的地址。

推荐做法：装 ICSx⁵（开源免费）。打开它 → 右上角「+」→ 粘贴地址 → 保存。以后每款游戏在它里面是一个独立日历，删哪个都不会连带，也不受厂商日历的账号机制影响。

用系统日历也行，但有代价：

  1. 打开日历 App，找「设置」或「添加日历」里的 从网址添加 / 通过网址订阅
  2. 把地址粘进去，命名随便写，确认
  3. 它会定期去这个网址拉最新数据。注意：这样加的多个订阅会被塞进同一个账号，删一个会全删，取消时改用「显示」开关
我是「一次性导入」的，怎么取消

一次性导入的日程存在你手机本地，外面够不着，只能在日历 App 里删：

  1. 打开日历 App，搜索框输入游戏名，比如「原神」
  2. 搜出来的每一条都能单独删（iPhone 点进去 → 删除日程；安卓长按 → 删除）
  3. 嫌麻烦就改用上面的订阅，以后取消只需删一个日历

为什么这里不能点一下就远程删掉？日历订阅是只读的，谁订了只有谁的手机知道。所以取消这一步只能在手机端做，我把它压到三次点击以内。

这是静态版，和完整版有什么区别

本页所有内容都由浏览器自己算，没有任何服务器参与，所以能免费挂在 GitHub Pages 上，谁都能开一份。

  1. 能做的事：勾选任意几款，一键生成合并的日历文件导进手机；按游戏订阅固定的一份。
  2. 做不到的事：给"原神 + 鸣潮"这种任意组合生成一个可订阅的网址。订阅地址只能是一个事先做好的文件，所以只有按游戏一份、和全部一份。
  3. 数据怎么更新：维护者改了 events.py 并重新生成，页面和订阅文件一起变；订阅的人手机自动跟上，导入的人需要重新导一次。

需要任意组合的订阅链接，用仓库里的完整版（Python 服务端），那边一个网址就能按你选的组合现算。

标「官方确认」的来自官方公告，「预估」是按版本周期推算，「待定」是官方还没公布日期。
「规则推算」是兑换码截止时刻：官方还没公布，但按每款游戏历次的口径能卡到分钟，误差一般在 1 小时内。
